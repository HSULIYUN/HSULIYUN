## 關於我

把複雜的想法變成能實際運作的系統，是我最喜歡做的事。前端寫得出介面，後端撐得住邏輯，AI 的部分也能自己串接、部署上線。

- 全端工程背景，習慣獨立完成一個功能從資料庫到畫面
- 專注於把 AI 能力（LLM、影像辨識）實際整合進產品，而不只是做 demo
- 對電腦視覺與模型應用特別感興趣，YOLO / OpenCV 是常用工具
- 台灣

<br>

## 技術足跡

**前端** `React` `Vue.js` `Next.js` `jQuery`

**後端** `Node.js` `Java` `Spring` `Spring AI` `Freemarker`

**AI / 電腦視覺** `YOLO` `OpenCV` `PyTorch` `Hugging Face` `LLM 應用整合`

**開發語言** `Python` `JavaScript` `Java` `HTML / CSS`

## 目前在做的事

- 開發整合 AI 能力的全端應用
